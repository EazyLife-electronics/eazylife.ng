01 · WHAT AN OP-AMP DOES

A high-gain differential amplifier

An operational amplifier has inverting (−) and non-inverting (+) inputs and an output. It amplifies the difference between its input voltages. In most useful linear circuits, negative feedback controls the closed-loop behaviour.

Vout = Gain × Vin
02 · IDEAL MODEL

Useful assumptions, not a perfect device

An ideal op-amp model assumes infinite open-loop gain, infinite input impedance, zero output impedance and unlimited bandwidth. Real devices have finite gain and bandwidth, input offset, bias currents, output-current limits and common-mode/input-voltage restrictions.

03 · NEGATIVE FEEDBACK

The circuit sets the gain

With suitable negative feedback and operation within its limits, the output moves to make the input difference very small. This is often called a virtual short; it does not mean the two input terminals are physically connected.

04 · INVERTING AMPLIFIER

Gain from resistor ratio

For an ideal inverting amplifier, voltage gain is Av = −Rf/Rin. The output is inverted relative to the input. The input resistor and feedback resistor set the ideal gain, but the output must remain within the amplifier's supply and load limits.

05 · NON-INVERTING AMPLIFIER

Same signal polarity

For the ideal non-inverting amplifier, Av = 1 + Rf/Rg. The output has the same polarity as the input. The real amplifier's input common-mode range, output swing, bandwidth and supply arrangement still matter.

06 · COMPARATORS

Decide which input is higher

A comparator drives its output toward one of its output states according to which input is higher. Dedicated comparator ICs are often preferable for switching decisions. An op-amp used as a comparator may recover slowly from saturation and may not have suitable output behaviour.

07 · SIGNAL CONDITIONING

Buffers, filters and sensor interfaces

Op-amp circuits can buffer a high-impedance sensor, scale a signal, filter noise or amplify a small signal. Input range, biasing, reference voltage, noise, bandwidth and ADC range must be considered in a real interface.

08 · DEVICE SELECTION

Check supply and input/output ranges

Review supply-voltage range, input common-mode range, output swing, gain-bandwidth product, slew rate, input offset, noise, output current and stability with capacitive loads. Rail-to-rail wording must be checked against the actual datasheet specifications.

09 · LOW-VOLTAGE EXPERIMENT

Explore gain with a safe signal

Use a low-voltage dual or single supply appropriate to the selected IC and keep input/output signals inside its specified ranges. Start with a small signal and modest gain. Confirm pinout and power-supply pins from the exact datasheet before wiring.
