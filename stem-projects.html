Motion-activated security light

What to notice

When the room is still, the PIR output is LOW. Movement triggers a HIGH signal and starts the output hold timer.

Real PIR modules detect changes in infrared energy; they do not identify a person. The simulation uses a simplified retriggerable timer.
02 · DIGITAL I/O

Digital read & digital write

Press a tactile push button connected to a digital input. The Arduino reads HIGH or LOW and writes the matching state to an LED output.

ARDUINO INPUT / OUTPUT

What to notice

Digital signals have two logic states. With the pull-down model used here, a pressed button reads HIGH (1); released reads LOW (0).

Hardware note: use an INPUT_PULLUP wiring pattern or a correctly wired external pull-down resistor to avoid a floating input.
03 · ANALOG & PWM

Potentiometer to LED dimmer

Turn a virtual potentiometer. The analog input changes from 0–1023 and the Arduino maps it to a PWM output from 0–255 to dim an LED.

What to notice

The potentiometer provides a variable voltage. The Arduino ADC converts it to a number; PWM then controls perceived LED brightness.

On common Arduino Uno boards, analogRead is 10-bit (0–1023) and analogWrite uses an 8-bit PWM value (0–255) on supported pins.
